# Puck Dev Lab

Independent developer portfolio for AI applications, API integrations, automation tools, market-data experiments, and modern web software.

## Live site

This repository is deployment-ready as a static website and works with Vercel, GitHub Pages, Netlify, or any static host.

## Stack

- Semantic HTML5
- Responsive CSS
- Vanilla JavaScript
- GitHub for source control
- Vercel-ready deployment

## Purpose

Puck Dev Lab serves as a public developer landing page and project hub. It documents ongoing software experiments and provides a professional public URL for developer profiles and program applications.

## Local preview

Open `index.html` directly in a browser, or serve the directory with any local static server.
